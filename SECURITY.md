# Security Policy

## Supported versions

There are no long-term support (LTS) versions planned. Only the latest release
(and the `main` branch) receives security fixes; to get a fix, upgrade to the
latest release.

| Version         | Supported |
|-----------------|-----------|
| latest release  | yes       |
| older releases  | no        |

## Reporting a vulnerability

Please do not report security issues in a public issue.

Use the private vulnerability reporting of GitHub: open the
[Security tab](https://github.com/samuraiii/PuppetNetworkManagerModule/security)
of the repository and choose "Report a vulnerability".

Include the version of the module, the version of Puppet or OpenVox and of
NetworkManager, and the steps to reproduce the problem. Do not include real
secrets (passwords, keys) in the report.

The reports are handled on a best effort basis, there is no guaranteed response
time. A fix is released as a new version of the module and described in the
`CHANGELOG.md`.
